# Bingo 模式

[English](../../en-US/modes/bingo.md) · [返回游戏流程](../README.md)

## 当前状态

Bingo **尚未实现，当前版本不能选择或开始该模式**。

代码中已经存在 `BINGO` 模式标识，通用游戏框架也允许注册新的模式工厂；但插件启动时只注册 Manhunt。Bingo 目前没有运行时实现、监听器、角色、规则、特殊物品、胜负判断或记录详情。

## 已确定的共用流程

Bingo 实现后会复用以下生命周期：

1. 准备阶段选择角色并配置 Bingo 规则。
2. 模式校验参赛者和配置后进入 5 秒倒计时。
3. 倒计时结束时固定参赛者名单，由 Bingo 模式显式管理本局任务。
4. Bingo 模式负责生成目标、处理达成事件并判断胜负。
5. 游戏结束时统一取消模式任务并保存通用记录及 Bingo 专属详情。
6. 游戏进行中使用参赛者终止投票，结束后使用全体在线玩家重开投票。

## 尚待定义

在实现 Bingo 前，仍需确定：

- 单人、个人竞速或队伍竞速的角色模型；
- Bingo 卡片尺寸、目标池和随机生成规则；
- 物品获得、合成、拾取等事件如何计入目标；
- 连线胜利、全卡胜利或计分限时等胜负条件；
- 重复目标、死亡、离线和重连的处理方式；
- 模式规则、特殊物品、计分板展示及持久化字段。

上述内容在代码中尚无既定行为，本文件不会将它们描述成已支持功能。
