# Bingo 模式

[English](../../en-US/modes/bingo.md) · [返回游戏流程](../README.md)

Bingo 是红队与蓝队共享同一张 5×5 物品卡的生存竞速。最先完成任意横行、竖列或对角线的队伍获胜。

## 进入模式和选择队伍

服务器启动时仍默认使用 Manhunt。管理员在准备阶段执行 `/minehunt mode bingo` 后，所有在线玩家会重置为观众角色。

| 角色 | 队伍 | 说明 |
| --- | --- | --- |
| `red` | 红队 | 参与收集目标并共享红队进度。 |
| `blue` | 蓝队 | 参与收集目标并共享蓝队进度。 |
| `audience` | 观众 | 不参与目标检测；游戏中使用旁观模式。 |

执行 `/minehunt join red` 或 `/minehunt join blue` 加入队伍。两队都至少有一位在线玩家时才能开始。

## 模式规则

| 规则 | 默认值 | 说明 |
| --- | --- | --- |
| `card_seed` | `0` | 非零值会确定性生成相同卡片；`0` 会在开局时生成随机种子。 |
| `keep_inventory` | `true` | 参赛者死亡后保留背包和经验；关闭时仍会在重生后补发卡片。 |
| `pvp` | `false` | 是否允许红蓝队互相造成伤害；队友伤害始终关闭。 |

## 卡片生成

- 卡片固定为 5×5，共 25 个不重复物品，没有免费格。
- 目标池分为五个难度层级，每层随机选择五个物品。
- 难度按拉丁方阵排列，因此五行、五列和两条对角线都恰好包含每个难度层级的一个目标。
- 两队始终使用同一张卡片和同一个卡片种子。

## 开局

倒计时结束后，系统固定红蓝两队的在线参赛者，清空所有在线玩家的背包并传送到主世界出生点。参赛者进入生存模式，观众进入旁观模式，每位在线玩家都会获得一份不能丢弃的 `Bingo Card`。

右键卡片会打开 5×5 物品界面。每个格子的说明会分别显示红队和蓝队是否已经完成；使用 `/minehunt give card` 可以补发卡片。

## 完成目标和胜负

- 插件每 tick 检查在线参赛者背包，所以拾取、合成、烧炼、交易、容器取出和其他实际进入背包的来源都使用相同判定。
- 某队首次持有目标物品时永久点亮对应格子，并记录完成者和相对开局时间。
- 物品之后被使用、丢失或因死亡掉落，不会撤销已经完成的格子。
- 同一个目标可以由红蓝两队分别完成；重复获得不会重复计入。
- 每次点亮后检查五行、五列和两条对角线。第一支完成任意连线的队伍获胜。
- 如果两队在同一次背包扫描中同时形成连线，则本局为平局。

## 死亡、离线和重连

- 死亡不会淘汰参赛者；重生后恢复生存模式和 Bingo 卡片。
- 进行中离线不会清除玩家的队伍或已经贡献的目标。
- 原参赛者重连后恢复开局时的队伍；开局后新加入的玩家只能作为观众。
- 倒计时期间有参赛者离线时，倒计时会取消并返回准备阶段。

## 结束和记录

模式会保存卡片种子、25 个目标、每次完成的队伍/玩家/格子/相对时间、获胜连线，以及每位玩家贡献的目标。SQLite、MySQL 和 PostgreSQL 都使用独立的 `bingo_record` 模式详情表；数据库保存失败或超时仍会走通用的本地文件回退。

终止投票通过时本局没有胜者；正常连线结束后，结果侧边栏会显示胜方、双方完成数和总用时。
