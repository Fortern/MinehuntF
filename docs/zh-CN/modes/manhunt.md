# Manhunt 模式

[English](../../en-US/modes/manhunt.md) · [返回游戏流程](../README.md)

## 目标与角色

| 角色标识 | 显示身份 | 目标 |
| --- | --- | --- |
| `speedrunner` | 速通者 | 在所有速通者被淘汰前击杀末影龙。 |
| `hunter` | 猎人 | 追踪并淘汰全部速通者。 |
| `audience` | 观众 | 不参与胜负；游戏进行时使用旁观模式。 |

开始游戏至少需要一名在线速通者。当前实现不强制要求猎人存在。

准备阶段中，主世界边界缩小到 32 格，时间、天气和生物生成暂停，玩家以冒险模式等待。侧边栏显示当前规则。

## 开局流程

1. 玩家通过 `/minehunt join speedrunner`、`/minehunt join hunter` 或 `/minehunt leave` 选择身份。
2. `/minehunt start` 校验在线速通者数量并启动 5 秒倒计时。
3. 开局时清空所有在线玩家的背包，恢复生命、饱食度和等级，并传送到主世界出生点。
4. 速通者立即切换为生存模式。
5. 猎人暂时以旁观模式等待，不能移动；经过 `hunter_ready_cd` 秒后，猎人传送到出生点、切换为生存模式并获得追踪指南针。
6. 游戏恢复昼夜、天气和生物生成，难度设为困难，主世界边界扩大到 9,999,999 格。

## 游戏进行

### 速通者

- 按正常生存流程收集资源、进入下界和末地并击杀末影龙。
- 速通者死亡后被永久淘汰，并切换为旁观模式。
- 最后一个速通者被淘汰时，猎人获胜。
- 末影龙死亡时，速通者获胜。

### 猎人

- 猎人指南针每 5 tick 刷新一次目标位置。
- 目标与猎人在同一维度时，指南针指向目标当前位置。
- 目标位于其他维度时，主世界或下界中的指南针指向已记录的最近传送门位置；末地没有跨维度指向。
- 尝试丢弃专用指南针会取消丢弃并切换到下一个未淘汰且在线的速通者。
- 猎人死亡后暂时进入旁观模式，经过 `hunter_respawn_cd` 秒后恢复生存模式。
- 猎人重生时会补发专用指南针；游戏中也可以执行 `/minehunt give compass` 补领。

### 离线与重连

- 游戏开始时会固定本局参赛者名单。
- 参赛者重新上线后恢复原有阵营；其他玩家作为观众进入旁观模式。
- 离线速通者保留在本局名单中。指南针会保留其最后可用的追踪位置，切换目标时会优先寻找未淘汰且在线的速通者。

## 模式规则

规则只能在准备阶段修改，例如：

```text
/minehunt rule hunter_ready_cd 15
/minehunt rule friendly_fire false
```

| 规则 | 默认值 | 允许值 | 效果 |
| --- | ---: | --- | --- |
| `hunter_ready_cd` | `30` | `0`～`120` 秒 | 猎人开局等待时间。 |
| `hunter_respawn_cd` | `30` | `0`～`120` 秒 | 猎人死亡后的等待时间。 |
| `friendly_fire` | `true` | `true` / `false` | 是否允许同阵营玩家互相造成伤害。 |
| `hunter_intentional` | `false` | `true` / `false` | 是否允许猎人利用床或重生锚造成“刻意的游戏设计”爆炸；速通者不受限制。 |
| `speedrun_loot_up` | `true` | `true` / `false` | 提高烈焰棒和末影珍珠的获取机会，包括烈焰人、末影人掉落及猪灵交易。 |

两个倒计时规则的命令补全推荐值为 `0`、`15` 和 `30`，但所有 `0`～`120` 的整数都有效。

## 结束与记录

- 末影龙死亡：速通者正常获胜。
- 全部速通者死亡：猎人正常获胜。
- 终止投票通过：游戏以“已终止”结束，没有胜者。
- 结束时所有在线玩家恢复生存模式，并显示胜者和对局结果侧边栏。
- 对局记录包含阵营成员、世界种子、开始与结束时间、首位进入下界和末地的玩家及时间，以及玩家战斗、资源和物品统计。
